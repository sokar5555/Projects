# Projects

## Repository Projects

- **[Optimizing Frozen Pizza Sales Strategy for Regork](./2024_BANA7025_group09_finalproject.html)**  
  An R Flexdashboard data analysis report (BANA7025) using Regork grocery transaction, product, and demographic datasets to uncover frozen pizza sales trends, age-group purchasing patterns, and co-purchased items for targeted marketing recommendations.

- **[Modeling a 4-Way Intersection](./Modeling%20a%204%20way%20intersection)**  
  A discrete-event simulation study (BANA7030) built in Arena modeling rush-hour traffic at the Oak & Burnett 4-way intersection using observed arrival and signal-timing data to evaluate improvements for reducing vehicle wait times. Includes the Arena model, traffic dataset, and presentation.

- **[Statistical Computing Project — Identifying Mood Disorders in Patients](./Statistical%20Computing%20Project)**  
  A machine learning classification project (BANA6043) evaluating and tuning KNN, Decision Tree, Random Forest, and Extra Trees models on patient survey data to assist in diagnosing mood disorders. Includes the JupyterLab report and presentation slides.

- **[Marketing Project Plan — Breakfastables](./Marketing%20Project%20Plan%20Final.docx)**  
  A marketing plan proposing *Breakfastables*, a breakfast line extension for Kraft-Heinz's Lunchables brand, covering situation and industry analysis, product/pricing/promotion/distribution strategies, and financial projections.

- **[3D Modeling Projects](./3D%20modeling%20Projects)**  
  A collection of WebGL and Three.js 3D graphics projects and coursework:
  - [Assignment 1](./3D%20modeling%20Projects/Assignment1): 3D geometric primitives and a wireframe humanoid figure with orbit controls.
  - [02viewing](./3D%20modeling%20Projects/02viewing): Dual-viewport scene combining a stereoscopic perspective camera with fly controls and an orthographic top-down view.
  - [Assign3](./3D%20modeling%20Projects/Assign3): 3D cubic Bézier curve visualization with control point markers and orbit controls.
  - [Cardboard](./3D%20modeling%20Projects/cardboard): Google Cardboard stereoscopic WebGL demo with device orientation controls.

- **[Undergraduate Projects](./Undergraduate%20Projects)**  
  Early software engineering projects and prototypes:
  - [Client-Server-Test](./Undergraduate%20Projects/Client-Server-Test): A Java client-server chat application (`Chat Client.jar` and `ChatServer.jar`).
  - [Watson Node Script](./Undergraduate%20Projects/watson%20node%20script.js): A Node.js interactive CLI chatbot script using IBM Watson Assistant V2 for intent detection and playlist creation workflows.
